# SmartAttend Landing Page

**Team:** TechVision Developers (Group 7) | **Course:** BSE2201 Software Engineering Foundations

## Project overview
A landing page introducing our team, the problem of manual student attendance, and our proposed system, SmartAttend, a digital attendance management system. Scope is the landing page only.

## Technologies
HTML5, CSS3 (responsive, no framework), JavaScript (mobile menu), Git/GitHub, Jira, Netlify/GitHub Pages.

## Setup
1. `git clone <repository-url>`
2. Open the folder in VS Code.
3. Open `index.html` in a browser (or use the Live Server extension).
4. Create a branch named with the Jira key, e.g. `SCRUM-8-team-section`, commit, push and open a pull request.
